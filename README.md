# SIEM-ThreatHunt-Lab 🚨🔍💻

A practical cybersecurity project showcasing SIEM log analysis, threat hunting methodologies, MITRE ATT&CK mapping, and digital forensics basics using open-source tools.

## 🔧 Tools & Frameworks
- Wazuh + ELK Stack
- MITRE ATT&CK Framework
- Sigma Rules
- Volatility, Autopsy, FTK Imager

## 📌 Objectives
- Simulate log ingestion and create custom detection rules
- Perform structured threat hunts using real-world hypotheses
- Map detections to MITRE ATT&CK techniques
- Conduct basic memory and disk forensic analysis

> For educational and demonstrative purposes only. No real user data involved.
